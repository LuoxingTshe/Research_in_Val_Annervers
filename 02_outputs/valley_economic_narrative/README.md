# 河谷产业演变叙事（景观设计作业用）

2026-10-08 定稿。用途：景观设计作业的背景叙事，不是学术论证。页码中 Viallon 为印刷页码，Savoy 为 PDF 页码。

## 结论

20 世纪中叶以来，河谷已从以农牧为主的传统经济，转向以旅游和建筑业为主的结构。残存的第一产业通过公共牛舍、奶酪加工、葡萄酒与节庆旅游、bisses 修复等途径，与旅游及景观维护互相依存；水电设施也逐步承担起造雪、灌溉、供水和旅游等多重用途。

写作提示：“战略引导”和“可持续”放在设计目标里写（“本设计提出……”），不要写成现状判断。文献中这种产业交织主要由补贴、市场压力和地方的逐案安排推动，整体是否可持续尚无评估。

## 设计叙事

**过去：沿垂直方向迁移的农牧景观。** 全家按季节在不同海拔之间迁移：冬天在河谷底部（Sierre 一带）种葡萄，春天上 mayens，六月中旬起把牛赶上高山草场三个月，九月底下山收葡萄（Viallon p.197）。bisses 把冰川水引到草场、村旁草地和葡萄园（Stevenson 1946, p.2）；Bisse Roux 与 St-Luc 大渠见于 1500–1600 年代文献（Savoy p.101）。

**转折：20 世纪中叶。** 人口外流到罗讷河谷的铝厂和葡萄园，1970 年代降至 1440 人的低点（Viallon p.190）；1950 年代起农业衰退、草场荒弃（p.217）。Gougra 水电站建成；1960 年代初滑雪旅游起步。

**现在：一二三产业交织。**
- 产业结构：1133 个全职当量岗位中，第一产业占 5%、第二产业占 20%、第三产业占 75%；年均约 41.8 万过夜人次，其中三分之二在冬季；第二住宅占 76%（Viallon p.191–192）。
- 牧业与旅游：1961 年起建公共牛舍，为维持景观、服务旅游；1977 年以来载畜率上升 29%（p.216–218）。
- 农产品与体验：公社年均拨约 60 万瑞郎支持农业（含新奶酪厂），bourgeoisie 的酒窖、葡萄园劳作日并入旅游活动（p.207、225）。
- 林业：森林联合体一半收入来自非林业业务，推出木屑供热（p.209、215）。
- 水电设施的多用途：Moiry 水库成为旅游热点，同一套设施还用于人工造雪（约 33 万 m³/年，2006–07 年协议）、bisses 供水、Chippis 饮用水，以及水坝参观、via ferrata（Savoy p.85–87、95）。
- bisses 修复：既恢复灌溉，也开辟徒步线路（Viallon p.225）。

**未来：设计切入点。** 气候变暖之后，夏季更干、雪更少，各种用水之间的冲突会增加（Savoy p.110、114、122）；瑞士 43% 的冬季运动目的地极度依赖降雪（Weingartner）。2039 年 Gougra 特许权到期，是重新分配用途的窗口（Bagnoud 2022）。
